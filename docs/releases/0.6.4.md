# 远程访问 0.6.4

## 宿主兼容

本版本明确支持 **DeepSeek Harness 0.2.1-rc.2**。包的 `engines.dsh` 与相关运行时 peerDependencies 已更新为 `^0.2.1-rc.2`，构建依赖固定为本次验证版本。其他宿主版本未由本次验证覆盖。

仍在 DSH 0.2.0-rc.2 的用户请继续使用 **0.6.3**，不要在旧宿主上强制安装本版。

## 更新

- 适配 DSH 0.2.1-rc.2 的原生 Connection、远程设置持久化及 WebServer 生命周期；不再伪装 isLoopback 或内嵌重复的官方连接模块。
- 通过原生 trustedHosts 合并 CLI 和插件的可信来源，支持修改后重新解析配置；保留 Origin 校验和密码门禁。
- 修复受密码门禁保护时 manifest 未携带凭据的问题。
- 为成功的哈希 JS/CSS 响应补充私有不可变缓存；HTML、API、错误响应及带 Cookie 的响应不进入该缓存策略。
- 浏览器从 BFCache 恢复时调用原生重连，普通聚焦不触发重复连接。

## 验证与升级

已验证真实 DSH 配置合成、非本机来源设置、信任来源热更新、服务重启重连、正式域名登录与 WebSocket，以及 manifest 和静态资源缓存。

安装：`dsh plugin --profile web add @lemoncat7/dsh-remote-settings-compat@0.6.4`。

请先备份配置与插件数据，升级到上述宿主后再安装本版，并重启实际使用的 Profile（桌面端按其 Profile 操作）。本次不修改 DSH 核心源码，不清理或迁移生产会话数据。

详见 [DSH 0.2.1-rc.2 兼容说明](../dsh-021-compatibility.md)。
