# 0.6.5 — DeepSeek 账号远程辅助登录

- 远程访问设置新增官方账号辅助登录：打开官方授权页面后，将本机回调地址粘贴回设置页完成登录，无需 SSH。
- 辅助流程绑定发起浏览器，固定回调路径，不跟随重定向，不记录授权码；state、PKCE 校验和凭据保存继续由 DSH 官方账号服务负责。
- 拒绝其他浏览器、重复提交、过期和旧流程；不确定的网络结果只刷新状态，不自动重放授权码。
- 入口只允许通过已登录密码网关和可信 Origin 使用；旧宿主未提供 deepseekAccount 时不影响原远程访问功能。

适配 DSH 0.2.1-rc.2。使用说明见 README 的“DeepSeek 账号远程辅助登录”。
